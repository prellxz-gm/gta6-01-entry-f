Costa Verde is a 3D open-world crime game in a golden-hour coastal city: drive and steal cars, outrun a 5-star police dispatch with helicopters and roadblocks, complete 10 story missions, and build a criminal empire with territory income, stunt ramps, district standings, a getaway-driver crew, garage upgrades, radio stations, and street races — all playable in a desktop browser from static files.

## Run it

```sh
node main.ts
```

Then open `out/game/index.html` in desktop Chrome to play.
